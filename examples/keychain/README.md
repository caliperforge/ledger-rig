# keychain example

Runs solana-keychain against two rig devices. Both workflows build the harness in `harness/keychain/`.

- `.github/workflows/keychain-307.yml` runs the two-device scenarios and the busy-race repeats: [keychain-307.md](keychain-307.md).
- `.github/workflows/keychain-runbook.yml` runs the runbook phases: [runbook.md](runbook.md).
